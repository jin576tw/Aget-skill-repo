# 模型派工

適用主會話委派 subagent 及 COORD 派獨立 session，不構成自動委派授權。

派工前讀 Aget rules/model-profiles.json 的目標模型 tier 與 directives。記錄任務 scale（範圍、耦合、風險、不確定性）、選定模型、effort 與理由，不固定以檔案數或角色選模型。

- 明確規則的整理、分類與小型固定任務優先 efficient；範圍清楚的多步實作及驗證用 balanced；架構、安全或高度不確定工作用 frontier。選足以完成任務的最小配置。
- 使用者指定優先。機械式且可直接核對的工作從 low 起步，範圍明確且需多步判斷的工作從 medium 起步。依宿主實測的選項設定；不支援 effort 時省略並說明。
- 完整對話派工沿用主會話設定。其他派工若宿主允許覆寫，明確傳入模型與 effort。既有 session 核對實際設定，建議 effort 不阻擋派工。無法指定或確認時記錄限制，避免默默換模型或聲稱已套用；額外 CLI 需有本次任務授權。
- 結果不足時先補上下文與可重跑的驗證。仍有具體推理缺口時，同模型提高一級並重查該缺口；有模型能力不足的證據時再升模型。記錄實際配置及原因，額外付費與重派遵循測試批次預算。
- max／ultra 依使用者或適用專案契約明確指定使用。其他可用級別依宿主與已核准的批次預算調整。
- efficient 任務用「目標／輸入與範圍／明確規則／步驟／完成標準／不做的事」。
